# RAF INTERCEPT — MVP

Stage 1 playable prototype for the RAF fighter-controller game.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Current features

- Radar-style display
- Moving simulated tracks and fighters
- Select target/fighter
- Vector command slider
- Basic intercept-vector scoring
- Fuel tracking
- Training assistance toggle
- Pause/reset
- Responsive layout
